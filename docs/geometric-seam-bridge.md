# Experimental geometric Continuum seam bridge

The reported failure is a small whole-frame zoom/shift at a progressive Continuum
join, especially a top-edge reveal. The released one-token DC bridge addresses
spatial means, not geometry. No decoded run has yet established the cause or
validated this experimental correction.

## Scope and execution

Only `MiniMax H3 Progressive Mixed-Grid Continuum` exposes the optional
`suffix_geometric_bridge` boolean, default **false**. Old workflows retain their
DC-only output. First chunks without a protected prefix retain their existing
progressive path. Generic Target Input and Target-Sparse UI are unchanged.

The low-grid carrier's protected rows do not condition H3: mixed-grid block 0
patchifies the original target-grid prefix with native visual-conditioning noise,
substitutes target-prefix RoPE/modulation rows, and the last block discards those
prefix outputs. The handoff probe supplies the real generated low-grid suffix.
A downsampled COPY of the exact prefix supplies temporal context to the learned
3D provider; its returned prefix is never authoritative.

`build_handoff_state` now has an invocation-local clean-video hook after provider
validation and before conditional re-noising. At that point the original exact
prefix, learned prefix, and learned suffix coexist. The hook measures geometry
on the original provider output even when the option is off. Accepted correction
runs on that clean output. The deterministic re-noise tensor is never warped or
regenerated by the hook. Audio remains the original packed sampler state.

Geometry precedes DC. A temporary diagnostic copy of the aligned last learned
prefix supplies DC calibration. DC still changes only the first suffix token.
The learned prefix in the hook result remains unchanged and is subsequently
replaced by the authoritative target-grid prefix. The existing exact-prefix
checks after target-stage sampling remain mandatory. No extra H3 evaluation,
VDN metadata change, sampler history, conditioning change, or mask change occurs.

If geometry is off or rejected, the hook returns the original tensor object.
The released inverse-clean-recovery/DC/state-delta arithmetic runs unchanged,
including its float rounding. Numerical runtime tests compare that path bitwise.

## Registration contract

Fit `sx, sy, tx, ty`, with no rotation or shear. Coordinates are centred on pixel
centres, and parameters map **output to input**:

```
input_x = sx * (output_x - (W-1)/2) + (W-1)/2 + tx
input_y = sy * (output_y - (H-1)/2) + (H-1)/2 + ty
```

Positive `tx` therefore moves displayed structure left. Normalized affine-grid
translations are `2*tx/W` and `2*ty/H`; a forward point displacement would instead
use reciprocal scale and translation `-tx/sx`, `-ty/sy`.

The representation uses all channels of the last up-to-three paired tokens,
a 5x5 spatial low-pass, an area reduction capped at 48 pixels on the long axis,
and channel-wise centring/normalization. Fixed three-pixel interior margins keep
padding out of the objective. Clipped squared normalized residuals limit local
outlier influence. A deterministic coordinate search refines scale increments
from 0.02 to 0.0025 and translation increments from 1 to 0.125 latent pixels.
It runs without autograd. Small candidate scoring uses NumPy elementwise
operations on CPU to avoid per-candidate GPU synchronization and CPU thread-pool
launch overhead; global thread settings remain untouched. NumPy is already a
ComfyUI dependency and is declared explicitly for this package.

Application requires:

- at least two paired prefix tokens and enough spatial information in both axes;
- at least 15% objective improvement, aligned error at most 0.25;
- a separated optimum along each of the four parameter axes;
- independent token fits within 0.0075 scale and 0.375 latent pixels of the joint fit;
- scale deviation at most 0.03 and translation at most min(1.5 pixels, 2.5% of that axis).

The wider search permits 0.06 scale and 3-pixel offsets so an out-of-bounds
optimum is rejected rather than silently treated as a valid edge-of-search fit.
The confidence field is an uncalibrated deterministic gate score, not a
probability. Nonfinite, unsupported, low-information, ambiguous, unstable, and
poorly aligned comparisons receive explicit rejection reasons. Very small or
extreme-aspect inputs are diagnostic no-ops. These thresholds are synthetic-test
engineering bounds, not empirically established H3 quality thresholds.

Warping uses one float32 bilinear resampling per corrected token, casts back to
the original dtype/device, uses `align_corners=False`, and extends border values.
Border extension avoids invented zero-valued edges; it can stretch edge content.
The fraction sampling beyond original pixel centres is recorded. Reflection
would invent mirrored content. These decisions follow the coordinate semantics
of [grid_sample](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.grid_sample.html)
and [affine_grid](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.affine_grid.html).

The provisional suffix window has weights `(1, 0.5, 0.25)`, capped by available
suffix length. Translation scales by weight and scale interpolates in log space.
Each token is resampled once; tensors are never crossfaded. Later suffix tokens
remain exact. The authoritative prefix is never warped.

A stable last-three-prefix fit is recorded as `persistent_bias_candidate`; it
does **not** establish persistent bias throughout generated content. Full-suffix
warping is deliberately deferred pending real-media evidence. A temporal-only
jump never drives correction. If paired geometry is identity but the temporal
join is abnormal, this bridge rejects it; a motion-aware trajectory intervention
requires separate evidence. The short window itself may create delayed wobble;
that is an explicit validation gate, not an assumed solution.

## Metrics and hypothesis discrimination

Return the full `H3_FLOW_METRICS` JSON (existing metrics/probe connection) and the
Continuum Decode Context report. Each continuation emits:

| Event | Evidence |
| --- | --- |
| `mixed_grid_geometry` | Actual grids, independent axis ratios and anisotropy; paired-prefix estimate, identity/aligned errors, relative improvement, confidence and token stability; requested/accepted/reason; applied transforms and count; out-of-bounds fraction; temporal boundary before/after geometry; prefix-motion baseline; pre/post-alignment DC residuals and post-DC boundary residual; transfer prefix exactness; diagnostic time |
| `mixed_grid_transfer` | Existing raw, low-pass, DC splice residuals before/after bridge; DC settings; clean measurement origin |
| `mixed_grid_complete` | Final accepted-latent boundary registration and existing seam residuals; final authoritative-prefix exactness |

Consecutive-time registration is labelled by context as a boundary or natural
motion baseline; a one-token comparison cannot pass the bridge's stability gate.
Its fitted parameters/errors remain diagnostic. Compare these with paired-prefix
measurements rather than interpreting a temporal fit as proof of a seam defect.

- **Transfer mismatch:** corresponding prefix tokens need a stable nonidentity
  fit. This implicates transfer or its downsampled context, not necessarily the
  whole generated suffix.
- **Trajectory mismatch:** paired prefix aligns, but generated boundary differs
  materially from the preceding natural-motion baseline. Motion still confounds
  that inference; inspect decoded media.
- **High-stage/decode candidate:** compare transfer and final-latent measurements.
  A jump appearing only after high-stage sampling implicates that stage. A visible
  decoded join despite unremarkable latent measurements warrants checking the
  temporal VAE/context/assembly path. Latent registration alone cannot prove a
  decode-only cause or perceptual continuity.

The audited provider contract uses exact target H/W, the average of the two scale
ratios for its scale embedding, normalization once, and returns input dtype/device
after offload. Continuum assembly trims time; it does not spatially resize these
frames. Flow's decode context appends five real future tokens only at bit-exact
whole-cycle overlaps; it changes neither accepted chunks nor assembly durations.
Those paths are unchanged.

The supplied RALU paper (2507.08422v3, section 3) discusses high-frequency aliasing
and noise/timestep mismatch. It does not establish the cause of this whole-frame
Continuum seam. No RALU noise correction or schedule change is imported here.
The supplied real-run log `Pasted text(20260907-144815).txt` was not available in
this implementation session. No model weights or decoded-media validation were
available locally.
